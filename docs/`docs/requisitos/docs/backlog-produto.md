# Product Backlog

## 1. Organização do Quadro
O Product Backlog operacional do projeto está mantido na ferramenta **GitHub Projects** no repositório.

## 2. Estrutura de Estados
* **A fazer (To Do):** Itens aguardando desenvolvimento.
* **Em andamento (In Progress):** Tarefas em execução pelo grupo.
* **Em revisão (In Review):** Artefatos ou código em verificação.
* **Concluído (Done):** Tarefas finalizadas e validadas.

## 3. Priorização para a Sprint 2
Os itens selecionados para a Sprint 2 focam na definição dos Requisitos Funcionais (RF-01 a RF-05) e na criação do protótipo/estrutura básica da aplicação web para gestão de torneios.
